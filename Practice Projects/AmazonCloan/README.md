# Amazon Homepage Clone

A static front-end clone of the Amazon homepage, developed to practice and demonstrate fundamental web development skills. 

## 🔗 Live Demo
[View the live project here](https://amazon-homepage-clone-yogesh23.netlify.app/)

## 🛠️ Technologies Used
* **HTML5:** Semantic structure and layout.
* **CSS3:** Custom styling, Flexbox for alignment, and UI design.
* **FontAwesome:** Icons for the search bar, location, and shopping cart.

## 📌 Features
* **Navigation Bar:** Includes logo, location selector, functional-looking search bar, language dropdown, and cart icon.
* **Hero Section:** Background promotional image with an informational alert banner.
* **Product Grid:** Flexbox-based layout displaying various product categories (Laptops, Gaming Accessories, Fashion, etc.) mirroring Amazon's card-style UI.
* **Footer:** Multi-section footer with links and a clean "back to top" layout.

## ⚠️ Known Limitations
* **Non-Responsive:** This project was built primarily for desktop view using fixed pixel dimensions. It does not adapt to mobile or tablet screens.
* **Static Content:** All links, dropdowns, and buttons are visually represented but lack backend functionality or interactive routing.
