# Netflix India Homepage Clone

A static front-end clone of the Netflix India landing page, built with HTML and CSS to replicate the visual layout and responsive behavior of the original site.

## 🔗 Live Demo
[View the live project here](https://streming-site-clone-yogesh23.netlify.app/)

## 🔗 Overview
This project is a structural and visual replication of the unauthenticated Netflix India homepage. It includes responsive design adjustments across multiple breakpoints, layout structuring, and embedded media elements to mimic the live user experience.

## 🛠️ Technologies Used
* **HTML5:** Semantic page structure (header, main, section, footer).
* **CSS3:** Custom styling, Flexbox, CSS Grid (for the footer), and Media Queries for responsive breakpoints.

## 📌 Features
* **Hero Section:** Background image with an overlay, functional-looking language selector, and an email signup form.
* **Feature Sections:** Alternating text and media components (TVs, mobile devices, kid's profiles) with embedded, auto-playing videos.
* **FAQ Section:** Static representation of the Netflix Frequently Asked Questions accordion.
* **Responsive Design:** Custom media queries handling layouts for desktop, tablet, and mobile viewports.
