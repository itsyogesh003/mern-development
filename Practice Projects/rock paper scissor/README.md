# Rock Paper Scissors

A web-based interactive implementation of the classic Rock Paper Scissors game, designed to track scores and evaluate win/loss conditions against a randomized computer opponent.

## 🔗 Live Demo
[View the live project here](https://peppy-sprite-261c9a.netlify.app/)

## 🔗 Overview
This project is a lightweight, frontend-only application. It utilizes vanilla JavaScript to handle game logic, DOM manipulation, and event listening, alongside CSS flexbox for structural alignment.

## 🛠️ Technologies Used
* **HTML5:** Semantic structure and element targeting.
* **CSS3:** Flexbox layout, hover states, and dynamic visual feedback.
* **JavaScript (ES6+):** Arrow functions, ternary operators, and standard Math libraries for randomized computer choices.

## 📌 Features
* **Interactive UI:** Clickable choice elements with active hover states.
* **Dynamic Score Tracking:** Independent variables tracking both user and computer scores, updating the DOM in real-time.
* **Conditional Messaging:** An adaptive message container that announces the winner, loser, or a draw, accompanied by color-coded visual cues (green for win, red for loss).
