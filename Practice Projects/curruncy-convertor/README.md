# React Currency Converter

A responsive, single-page currency conversion application built with React and Tailwind CSS. It fetches real-time exchange rates to provide accurate conversions across multiple global currencies.

## 🚀 Features
*   **Real-Time Rates:** Integrates with the ExchangeRate-API for up-to-date currency values.
*   **Swap Functionality:** One-click swap between base and target currencies.
*   **Responsive UI:** Clean, mobile-friendly interface styled with Tailwind CSS.
*   **Dynamic Dropdowns:** Auto-populates currency options based on the API payload.

## 🛠️ Technologies Used
*   **Frontend:** React 18 (Vite)
*   **Styling:** Tailwind CSS
*   **State Management:** React Hooks (`useState`, `useEffect`)
